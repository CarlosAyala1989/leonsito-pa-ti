# leonsito-pa-ti

Un rompecabezas interactivo y adaptable a celular: arma el león tocando o arrastrando sus siete piezas.

## Publicar en GitHub Pages

El sitio usa solo HTML, CSS y JavaScript. El flujo de GitHub Actions en .github/workflows/pages.yml publica el contenido de la rama principal en GitHub Pages cada vez que recibe un cambio.

Si Pages todavía no está habilitado en el repositorio, abre **Settings → Pages** y elige **GitHub Actions** como origen de publicación.
